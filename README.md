# AI & Operations wiki

Myntmore's internal AI & Operations knowledge base, built from the Notion export of 25 Nov 2026: 465 pages and 14 tables in 12 sections.

- Full-text search across every page, heading and table row
- Active / inactive switch on every section, page and table, shared through Supabase
- Edit any page or table from the website (saved to Supabase, with full history)
- Deploys to Vercel as a static site (see [DEPLOY.md](DEPLOY.md))

Passwords, API keys and proxy logins from the export are shown as-is. Build with `python3 build.py --redact` to hide them.

## Files

| File | What it is |
| --- | --- |
| `index.html` | The whole site (HTML, CSS and JS) |
| `data.js` | All page content, generated by `build.py` |
| `assets/` | Images from the export |
| `api/status.js` | Vercel function: active/inactive switches (Supabase) |
| `api/content.js` | Vercel function: website edits (Supabase) |
| `api/_supabase.js` | Shared Supabase helper |
| `supabase/schema.sql` | Tables to create once in Supabase |
| `status.json` | Starting set of inactive items |
| `build.py` | Rebuilds `data.js` and `assets/` from a Notion export in the parent folder |
| `serve.py` | Runs the site locally at http://localhost:8765 |

## Run locally

```bash
python3 serve.py
```
