## PART A: ONE TIME FOUNDATION, Rs. 1,00,000 (30 hours)

This is the groundwork. Think of it as setting up the pipes and wiring before we start filling the house with content and conversations. Without this, everything we do later would be guesswork.

### 1. Technical SEO Foundation

This is about making sure Google and other search engines can actually read, understand and trust Vimana's website. If this part is broken, nothing else we do will matter, because Google simply will not show a site it cannot properly crawl or trust.

- Set up Google Search Console. This gives us a direct line into how Google sees Vimana's site, what errors it finds and how it is performing in search.
- Set up Bing Webmaster Tools. Same idea, but for Bing, so Vimana shows up there too.
- Install Google Analytics 4. This tells us how many people visit the site, where they come from and what they do once they land there. Without this, we are flying blind.
- Set up Google Tag Manager. A simple way to manage tracking on the site without touching the website's code every time.
- Create and submit an XML sitemap. This is basically a map of the website that we hand to Google, so it knows exactly which pages exist and should be shown in search.
- Audit the robots.txt file. This file tells search engines which parts of the site they are allowed to look at. We make sure nothing important is accidentally hidden from Google.
- Check HTTPS and security. Making sure the site loads securely with the padlock icon, which builds trust with both visitors and Google.
- Audit canonical tags. This avoids Google getting confused by similar or duplicate pages and picking the wrong one to show.
- Clean up URL structure. Making links short and readable, like vimana.com/drone inspection instead of a string of random numbers and symbols.
- Plan the site's internal structure and linking. How pages connect to each other, so both visitors and Google can navigate the site easily.
- Audit mobile responsiveness. Making sure the site works well on phones, since most people researching Vimana will likely be on their phone first.
- Audit Core Web Vitals (site speed and experience). Google directly rewards fast, smooth websites and penalizes slow, clunky ones.
- Optimize site speed (compress images, clean up code, set up faster loading). A slow website loses potential clients before they even read a word.
- Run a full crawl audit to catch broken links, redirect issues and orphan pages (pages nothing links to, so they get lost).
- Fix 404 errors and set up a proper "page not found" experience, so lost visitors are guided back rather than leaving.
- Map out redirects for any old or changed page links, so nothing breaks when pages move.
- Check for duplicate content, especially around www versus non www versions of the site, so Google does not see two versions of the same page as competing against each other.
- Implement structured data (schema markup). This is hidden code that explains to Google exactly what each part of a page means, for example, "this is a service," "this is a price," "this is a frequently asked question." It directly improves how Vimana shows up in search results. This covers organization schema, website schema, product and service schema, FAQ schema, breadcrumb schema, local business schema and review schema, wherever each one is relevant.
- Set up hreflang tags if Vimana ever targets multiple regions or languages.
- Set up favicon and site icons, the small logo shown in browser tabs and bookmarks.
- Review server log files (optional), to understand exactly how often and how deeply Google is exploring the site.
- Check current indexation status, meaning which pages Google has actually added to its results so far.
- Create an llms.txt file. This is a newer file, similar to robots.txt but built for AI tools like ChatGPT, giving them a clean, direct summary of what Vimana does.
- Make sure AI crawlers (used by ChatGPT, Perplexity, Google's AI tools) are not accidentally blocked, and decide deliberately how open we want to be with them. This directly affects whether Vimana shows up in AI generated answers.

### 2. On Page SEO (Making the Website Itself Work Harder)

This is about shaping the actual content and pages on Vimana's website so they clearly speak to the topics and problems Vimana solves, in the language potential clients are actually searching for.

- Research and map keywords. Finding the exact words and phrases people actually type or ask when they are researching drone based inspection, autonomous UAVs, BVLOS and related topics, and matching the right ones to the right pages.
- Analyze top competitors and find gaps. Seeing what competitors are ranking for that Vimana currently is not, so we know exactly what to build next.
- Optimize title tags across all pages. This is the clickable headline shown in Google results, so it needs to clearly say what the page is about.
- Optimize meta descriptions. The short summary shown below the title in search results, which strongly influences whether someone clicks through.
- Fix heading structure (H1, H2, H3) on every page, so content is organized clearly for both readers and search engines.
- Add proper alt text to all images, describing what each image shows, which helps both accessibility and search visibility.
- Rename image files with clear, descriptive names instead of generic file names.
- Add internal links connecting related pages, helping visitors and Google understand how Vimana's offerings connect to each other.
- Identify content gaps compared to competitors, meaning topics or use cases Vimana should be talking about but currently is not.
- Optimize the homepage content so it clearly communicates what Vimana does within seconds.
- Optimize core service and product pages, so each one clearly targets the right audience and problem.
- Optimize the About and Contact pages, keeping the business name, address and phone number consistent everywhere, which builds trust with search engines.
- Clean up URL slugs (the last part of the page link) to be short and descriptive.
- Set up social sharing previews (Open Graph and Twitter Card tags), so links to Vimana's site look polished and professional when shared on LinkedIn, X or WhatsApp.
- Improve overall readability and credibility of the content, aligned with what Google calls Experience, Expertise, Authority and Trust. In simple terms, content that genuinely reads like it was written by people who know the industry.
- Add author bios and credentials where relevant, which builds trust with both readers and AI tools trying to judge credibility.
- Set up a proper blog and resources section on the site, since Vimana does not currently have one. This becomes the engine for almost everything else we do.
- Audit and clean up any thin or duplicate content, meaning pages with very little real value, either strengthening them or removing them so they do not drag the rest of the site down.

### 3. Off Page SEO (Building Vimana's Reputation Beyond Its Own Website)

This is about everything happening outside Vimana's website that still shapes how trustworthy and visible it appears.

- Set up and optimize Google Business Profile, if relevant, so Vimana appears properly on Google Maps and local search.
- Get Vimana listed on relevant industry directories, each one acting as a small vote of credibility.
- Check that Vimana's name, address and phone number are written identically everywhere online, since inconsistency confuses search engines and reduces trust.
- Audit Vimana's current backlink profile, meaning all the other websites currently linking to it, using tools like Ahrefs or Semrush.
- Disavow any toxic or spammy backlinks, if we find any that could be hurting Vimana's credibility.
- Study competitor backlinks to find sites that link to them but not yet to Vimana, giving us clear outreach targets.
- Set up and optimize Vimana's social media profiles across LinkedIn, Instagram, X, Facebook and YouTube, wherever relevant.
- Build an initial outreach list of blogs, publications and guest post opportunities.
- Check Vimana's presence on Wikipedia and Wikidata, which are key sources AI tools pull facts from when describing a brand.
- Explore a press release or brand announcement, if it makes sense.
- Build a list of potential influencer and industry partner collaborations.

### 4. AEO, Answer Engine Optimization

The goal here is simple. When someone asks Google, Siri or Alexa a direct question, we want Vimana's content to be the one that gets picked as the actual answer, not just another link in a list.

- Create a proper FAQ page with structured markup, so questions can show up directly in Google results.
- Research "People Also Ask" questions related to Vimana's core topics, since these reveal exactly what people are curious about.
- Rewrite key content so the very first lines directly and simply answer the likely question, since this is the format Google and AI tools prefer to quote from.
- Audit where Vimana is close to winning a featured snippet, the highlighted answer box that appears above all other results.
- Map out conversational, voice style questions people might ask (for example, "how can drones help EPC companies with inspection") rather than just short keyword phrases.
- Structure how to style content properly, so it can appear as a clear, expandable guide in search.
- Build a glossary of industry terms (drone, UAV, BVLOS, autonomous systems), helping both readers and AI tools quickly understand Vimana's world.
- Optimize for local, near me style voice searches, if relevant to Vimana's business.

### 5. GEO, Generative Engine Optimization

This is the newer, forward looking piece we discussed on the call. The goal is to improve Vimana's chances of showing up when people ask ChatGPT, Perplexity or Google's AI powered search things like "how can EPC companies use autonomous drones for inspection."

As Tejas showed on the call, when we searched for the best lead generation companies in Mumbai on ChatGPT, Myntmore came up as a result. That is exactly the kind of visibility we want to build for Vimana, in its own space.

To be clear, this does not mean ChatGPT or Perplexity will always recommend Vimana first. But by building a strong, consistent information ecosystem around Vimana and what it does best, we meaningfully improve the odds of it being surfaced when people ask relevant questions.

- Audit how clearly AI models currently understand who Vimana is and what it does.
- Rewrite the About Us page with clear, structured facts (what Vimana does, when it started, what problems it solves), since AI tools often pull directly from this page to describe a brand.
- Create a Wikidata entry for Vimana, which is a strong, trusted signal that feeds directly into how AI tools understand and describe brands.
- Make sure Vimana's description is consistent everywhere, website, social media, directories, press mentions.
- Test Vimana's current visibility on ChatGPT, Perplexity, Gemini and Google's AI Overviews for relevant questions, to set a clear starting point we can measure progress against.
- Structure content in clear question and answer, definition and list formats, since AI tools tend to pull cleanly from this kind of content rather than long, dense paragraphs.
- Build original data, statistics or research that Vimana can publish, since AI tools and journalists love citing original sources.
- Set up the llms.txt file (explained above).
- Decide deliberately how open Vimana wants to be to AI crawlers like ChatGPT's and Google's.
- Get Vimana genuinely mentioned on high authority sites likely to be read and cited by AI tools, including relevant Reddit threads, Quora answers and industry publications.

## PART B: ONGOING MONTHLY WORK, Rs. 30,000 per month

Once the foundation is in place, this is the work that keeps building Vimana's presence, month after month. Nothing here is a one time fix. Search and AI visibility is built gradually, through consistent, genuine effort, and this is exactly what compounds over time into real, long term visibility for Vimana. Every recurring item below has a clear, measurable target attached, so progress is easy to track month to month.

### Weekly

- Check Google Search Console for any manual penalties or security issues. Done every week, so nothing catches us off guard.
- Monitor that the website is up and running properly. Checked continuously, reviewed weekly.
- Resubmit the sitemap or ask Google to recheck new pages, done for every new page published that week.
- Publish 2 new blog posts, built around the topics and questions Vimana's potential clients are actually searching for. That is 8 to 9 articles a month.
- Add 3 to 5 internal links from every new post back to existing, relevant pages.
- Review where Vimana currently ranks for its top 20 target keywords, and track how that is moving week on week.
- Monitor new and lost backlinks, checked weekly.
- Track what the top 3 competitors are publishing and who is linking to them, checked weekly.
- Post 1 update on Google Business Profile a week, if relevant.
- Respond to any new reviews within 48 hours.
- Check that site speed has not slipped after any recent changes, checked weekly.

### Bi Weekly / Monthly

- Run a full technical health check across the site once a month.
- Review how the top 10 to 15 pages are actually performing, in terms of traffic, engagement and real business outcomes like inquiries or sign ups.
- Refresh and improve 3 to 5 underperforming pages a month.
- Run backlink outreach to 10 to 15 relevant sites a month, targeting 2 to 4 new quality backlinks a month.
- Audit structured data on any new pages or content, done monthly.
- Test Vimana's content against 10 to 15 target questions on Google and voice assistants a month, and tweak content to win more featured answers.
- Test how Vimana shows up across ChatGPT, Perplexity, Gemini and Google's AI Overviews for 10 tracked queries a month, and note where the gaps are.
- Add or update 5 FAQs a month, based on new questions people are asking.
- Send Ramesh a keyword ranking report every month.
- Send Ramesh a traffic and conversions report every month.
- Audit local business listings once a month, if relevant.
- Post around 8 genuine, useful answers a month across relevant Reddit threads and Quora questions on drones, UAVs, autonomous systems, industrial inspection, EPC, mining and BVLOS, with Vimana mentioned only where it is truly relevant. This keeps the activity credible and sustainable, and avoids anything that looks promotional or risks getting flagged.

### Quarterly

- Run a full site audit covering technical, on page and off page SEO together, once a quarter.
- Do a deep review of Vimana's full backlink profile and clean up anything harmful, once a quarter.
- Put together a competitor benchmarking report comparing Vimana against its top 5 competitors, once a quarter.
- Prune 10 to 15 percent of old or underperforming pages each quarter, either improving them, merging them with stronger pages, or removing them.
- Refresh the overall keyword strategy based on new opportunities and seasonal trends, once a quarter.
- Re test Vimana's visibility across the same tracked AI queries, to see how the trend has moved over the quarter.
- Expand and update structured data as new types of content get added, reviewed once a quarter.
- Review and refresh Vimana's Wikidata and entity information, once a quarter.
- Do a deeper dive into site speed and performance, with one dedicated optimization push a quarter.
- Sit down with Ramesh for 1 strategy review a quarter, walk through results and adjust the roadmap based on what is working.
