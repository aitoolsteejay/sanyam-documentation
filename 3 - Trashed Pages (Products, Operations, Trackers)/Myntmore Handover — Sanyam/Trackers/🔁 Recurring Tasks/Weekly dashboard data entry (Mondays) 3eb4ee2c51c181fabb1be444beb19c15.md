# Weekly dashboard data entry (Mondays)

Area: Reporting
Frequency: Weekly
Loom recorded: Yes
System: Dashboard
Tools: http://dashboard.myntmore.com, Waalaxy
When / how: Every Monday. Account managers enter their own clients' numbers (Waalaxy CSV import + replies, hot leads, meetings). The dashboard owner checks everything is complete, enters Myntmore/TJ/sales numbers, fixes issues and spot-checks the client portal.
