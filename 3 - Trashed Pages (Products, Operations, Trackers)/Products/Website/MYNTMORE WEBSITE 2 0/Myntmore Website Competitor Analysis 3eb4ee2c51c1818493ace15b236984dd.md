# Myntmore Website: Competitor Analysis

**Please read before filling the table:**

> This table is a full website competitor analysis framework.
Your job is to review each competitor website and fill every column as accurately as possible.
We will use this analysis to decide the structure, design direction, messaging, and functionality for the new Myntmore website.
> 

### ✔️ What is expected from you:

1. **Open each competitor website and study it thoroughly**
    
    – page structure, navigation, services, content depth, UX, UI, speed, mobile performance.
    
2. **Fill each column with specific observations**
    
    – not generic answers.
    
    Example:
    
    - Instead of “Good UX”, write “Strong visual hierarchy, bold typography, simple 5-tab navigation”.
3. **Rate honestly based on what you see** (1–5 or Yes/No where applicable).
4. **Identify patterns**
    
    – What most competitors are doing well
    
    – What they miss out on
    
    – What we can use to differentiate
    
5. **Highlight learnings** in the last column clearly
    
    – This is the most important
    
    – These insights will directly influence our website strategy
    

### ✔️ Minimum expected deliverables:

- At least **5–10 high-quality competitor website entries**
- Clean, concise, point-wise notes
- Accurate ratings, not guesswork
- Final recommendations in “What We Should Learn”
    - The competitor table ("Analysis") is in the child page **Analysis** below.

# 🎯 **Weighted Scoring System — Instructions (Add this above the table in Notion)**

> Purpose:
> 
> 
> To score each competitor website across critical parameters using weights.
> 
> Higher score = stronger, more strategic website direction for us to learn from.
> 

> How it works:
> 
1. Each parameter has a **weight (%)** based on importance.
2. For every competitor, rate each parameter **1–5**.
3. Add all weighted scores to get **Total Competitor Score (out of 40)**.

> Goal:
> 
> 
> Identify which websites have the best:
> 
- Structure
- UX/UI
- Messaging
- Speed
- Conversion
- SEO
- Content depth
    
    …so we know exactly what to emulate or outperform.
    

The weighted scoring table is in the child page **Weighted Scoring (untitled database)** below.

# 🔎 **Parameter Definitions (Add at bottom of Notion page)**

### **Design Quality (20%)**

Visual appeal, layout consistency, modernity, brand alignment.

### **Messaging Clarity (20%)**

How clearly the website explains:

- what they do
- who they serve
- why they’re different

### **UX & Navigation (15%)**

Ease of use, menu structure, scroll experience, page hierarchy.

### **Speed Performance (10%)**

Scores from Google PageSpeed Insights (mobile + desktop).

### **SEO Strength (10%)**

Blog strategy, ranking signals, metadata, technical SEO.

### **Content Depth (10%)**

Detailed pages, strong case studies, high-value insights.

### **Conversion Optimization (10%)**

CTAs, forms, chatbots, clarity of next steps, funnel strength.
